# Honesty and results (always on)

- Never invent, round up or hand-type experimental numbers. Report only values produced by the evaluation runner and saved in `results/`.
- Any number in a README, slide text or explanation that is not from `results/` must be labelled "illustrative example".
- Record every modelling assumption in `docs/ASSUMPTIONS.md`.
- Maintain `docs/LIMITATIONS.md` honestly: simulation only, simplified network model, synthetic data, twin is an approximation, no vendor integration.
- Include at least one scenario where the system performs poorly or abstains, and report it.
- Do not claim integration with any Nokia or other vendor platform. Use "compatible in concept with policy-based network automation" at most.
- Do not claim to be the first or only approach. State what is new: the safety loop (confidence-based abstention, predictive pre-check, measured baseline comparison).
