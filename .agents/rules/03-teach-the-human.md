# Teach the human (always on)

The human teammate has limited networking background and must defend this project to telecom experts.

After finishing each phase, create `docs/learning/phaseN.md` containing:
1. **What we built**, in simple words and one everyday analogy.
2. **Key terms**, each explained in one or two sentences (for example SLA, URLLC, jitter, Isolation Forest, false alarm).
3. **How the code fits together**, listing files and the role of each main function.
4. **What to try**, three small experiments the human can run by changing a config value.
5. **Quiz**, five questions with answers at the bottom.
6. **How a judge might attack this phase**, and an honest answer.

Keep the language simple. Do not move to the next phase until the human says they are ready.
